Investigation Engine

Every sentence is checked against the documents it cites. Contradictions and gaps are reported, not hidden.

Documents

PDF, DOCX, HTML, Markdown, CSV, JSON, JSONL or TXT, up to 10 MB. Uploading a file with the same name updates it: unchanged rows are skipped, changed rows get a new version, removed rows are deleted.

Search

Retrieval only, no language model. Each result shows its rank in the keyword list and in the semantic list, so you can see why it was found.

Evaluation

Measured by the evaluation scripts. Method, error analysis and every raw number are in EVALUATION.md.
